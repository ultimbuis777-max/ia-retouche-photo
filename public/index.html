Guide d'utilisation

Workflow de traitement

1
Déposez vos photos dans la zone d'upload (drag & drop ou bouton). Les images arrivent dans le dossier RAW et sont traitées automatiquement.
2
Validation automatique — images trop sombres, floues ou trop petites → envoyées dans À vérifier pour décision humaine.
3
Traitement IA — le pipeline analyse l'image, sélectionne le bon preset, améliore netteté, lumière et couleurs.
4
Score — chaque image est notée sur 100. Les meilleures sont copiées automatiquement dans Sélectionnées.
5
Exports sociaux — portrait 4:5 et carré 1:1 générés automatiquement pour chaque image retouchée.

Signification du score

> 70
Excellent
50 – 70
Correct
< 50
Faible

Score = netteté (50%) + contraste (30%) + luminosité (20%). Image rejetée en dessous de 45 → archivée dans failed.

Hover avant / après sur les images

Survolez une image dans la galerie pour voir un split avant / après retouche. La moitié gauche simule l'état original (désaturé, contrasté), la droite montre l'image traitée.

Retouche avancée

Le traitement local reste gratuit par défaut. La retouche IA avancée est optionnelle, utilise vos clés API personnelles si elle est activée plus tard, et rien n'est envoyé sans action explicite.
